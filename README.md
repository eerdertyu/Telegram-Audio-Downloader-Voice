# Unified Telegram Bot: X → Telegram + Voice to MP3

Один Telegram-бот объединяет два режима: мониторинг X с ручной модерацией и конвертацию голосовых в MP3. Работает один aiogram polling-процесс, поэтому два конкурирующих клиента Telegram updates не запускаются.

## Railway Variables

Обязательные:
- `BOT_TOKEN` — токен бота от @BotFather.
- `ADMIN_ID` — твой числовой Telegram user ID (админ новостной части).
- `X_BEARER_TOKEN` — Bearer Token из X Developer Portal.

Необязательные:
- `CHECK_INTERVAL` — интервал проверки X в секундах, по умолчанию 1800.
- `BATCH_IDLE_SECONDS` — пауза перед конвертацией голосовых, по умолчанию 8.
- `RAILWAY_VOLUME_MOUNT_PATH` — путь к Railway Volume; база сохраняется в `/data`, если каталог существует.
- `LOG_LEVEL` — уровень логирования.

## Переформатирование постов
- `/refil` включает режим: отправь следом текст, фото, видео или другой пост, и бот вернёт его в этот чат с кликабельной подписью `🔹 WZH | Игровые новости` со ссылкой на `https://t.me/wzhgame`.

## YouTube
- `/YouTube` запускает загрузку видео с YouTube. Отправь ссылку, выбери доступное качество и получи видео как документ (файл), не как Telegram-видео.
- Загрузка использует yt-dlp и ffmpeg. Лимит отправки по умолчанию — 49 МБ (`YOUTUBE_MAX_UPLOAD_BYTES` можно изменить). Если YouTube требует подтверждение «Sign in to confirm you’re not a bot», добавь `YOUTUBE_COOKIES_BASE64` в Railway Variables: это Base64 от экспортированного файла cookies YouTube в формате Netscape. Альтернатива — `YOUTUBE_COOKIES` с полным текстом такого файла. Cookies храни только в Railway Variables, не публикуй их и не добавляй в GitHub.

## Голосовые
- Отправь голосовые подряд — после паузы бот конвертирует их в MP3.
- `/name название` задаёт имя файлов; `/name` сбрасывает имя.
- `/done` обрабатывает партию немедленно.
- `/cancel` отменяет необработанную партию.
- `/audiohelp` показывает команды.

## Первый запуск на Railway
1. Подключи именно этот репозиторий `eerdertyu/Telegram-Audio-Downloader-Voice`.
2. В Variables добавь `BOT_TOKEN`, `ADMIN_ID`, `X_BEARER_TOKEN`.
3. Добавь Railway Volume и смонтируй его в `/data`.
4. Дай боту права администратора канала с правом публикации.
5. Оставь один запущенный worker с этим BOT_TOKEN.

## X API
Используется официальный X API v2 через Bearer Token. Запросы тарифицируются по плану X Pay Per Use и ограничены квотами. Проверь лимиты и стоимость в X Developer Portal. Видео и карусели в этой версии не скачиваются; прикрепляется первая доступная фотография.

## Хранение и ограничения
SQLite хранит источники, очередь и настройки. Без постоянного Railway Volume локальная база может потеряться при пересоздании контейнера. Не запускай второй экземпляр с тем же BOT_TOKEN. Секреты храни только в Railway Variables, не в GitHub.
